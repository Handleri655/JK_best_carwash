# JK Best Carwash

Premium-verkkosivut wow-efektillä — animoitu intro, kuplatehoste, scroll-animaatiot.

## Wow-efektit

- **Intro-splash** — Logo ja "BEST CARWASH" animaatio latauksessa
- **Kuplacanvas** — Interaktiiviset kuplat reagoivat hiireen
- **Hero-animaatiot** — Teksti paljastuu rivi riviltä, shimmer-efekti
- **Laskurit** — Palvelut, hinnat ja tyypit animoituvat numeroiksi
- **Cursor glow** — Hiiren seuraava valoefekti (desktop)
- **Scroll reveal** — Elementit ilmestyvät scrollatessa
- **Marquee** — Liukuva palvelunimien nauha

## Käynnistä

```bash
npx serve .
```

Avaa selaimessa osoite, jonka serve tulostaa.
